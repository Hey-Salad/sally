# Sally

HeySalad's AI shopping agent: a Chrome extension that fills an Ocado basket from your list, backed by a Cloudflare Worker API.

- `extension/` – Chrome extension (MV3)
- `api/` – Cloudflare Worker (Hono) API
- `docs/ROADMAP.md` – 1.0.29 and v2 plan

Follows the [HeySalad Engineering Standard](https://github.com/Hey-Salad/engineering-standard) (see STANDARD.md, AGENTS.md).
